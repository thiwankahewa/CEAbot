#---arm crash recovery (after rebuilding, restart the existing launch once)
# Standalone real/fake arm launches now restart a crashed ros2_control_node,
# reload both controllers, and retain the running scanner/MoveIt processes.
# Defaults: 5 s restart delay; at most 3 restarts per launch session.
# The scanner waits up to 120 s for active controllers + fresh joint feedback,
# then replans the interrupted view (up to 2 recovery retries for that view).
# Exhausted recovery halts the row without publishing scan completion.
# This handles process crashes, not a still-running but hung driver or the
# underlying network/Kortex timeout. Do not start a second robot launch.
# Build only the changed packages:
# colcon build --symlink-install --packages-select arm_controlling bench_robot
# source install/setup.bash
# ros2 launch bench_robot full_robot.launch.py robot_ip:=192.168.1.10 use_rviz:=false
# Optional launch overrides: arm_control_max_restarts:=3 arm_control_restart_delay:=5.0
# Scanner parameters: arm_recovery_timeout (seconds), arm_recovery_retries.

#---automatic Kinova fault reset (real hardware, enabled by default)
# auto_fault_reset:=false disables it; auto_fault_reset_max_attempts:=2 is the
# per-arm_manager attempt limit. Any failed reset blocks further automatic tries.
# For base JOINT_FAULT (16) with all actuator faults zero, recovery disables
# trajectory control and waits for stationary feedback and old goals to finish.
# It confirms single-level servoing, then follows the installed driver's reset:
# ApplyEmergencyStop twice, confirm its software-stop bit, then ClearFaults once.
# Pre-existing stops, physical emergency-line faults, and actuator faults are
# refused. Only the software-stop bit introduced by this attempt is permitted.
# Fault-free feedback and active controllers are required before scans resume.
# After ClearFaults, fault-free INITIALIZATION is allowed while waiting up to
# 10 s for a ready servoing state; trajectory control stays inactive meanwhile.
# Requires Kinova's Python Kortex SDK; source changes take effect on next launch.
